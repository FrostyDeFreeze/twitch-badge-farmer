# Badge Farmer

Собирает глобальные бейджи Twitch, которые выдаются за просмотр трансляций.

[English version](README.md)

Программа работает через внутренний API Twitch и клиент TV-приложения. Twitch не поддерживает такой способ официально, поэтому используй её на свой риск.

## Установка

Скачай готовую к запуску версию со страницы [релизов](https://github.com/FrostyDeFreeze/twitch-badge-farmer/releases).

Открой последний релиз и скачай архив для своей системы из раздела **Assets**.

| Система                   | Архив                           |
| ------------------------- | ------------------------------- |
| Windows x64               | badge-farmer-windows-x64.zip    |
| Linux x64                 | badge-farmer-linux-x64.tar.gz   |
| macOS с Apple Silicon     | badge-farmer-macos-arm64.tar.gz |
| macOS с процессором Intel | badge-farmer-macos-x64.tar.gz   |

Распакуй архив в папку, где хочешь хранить программу и её настройки.

Исполняемый файл называется `badge-farmer.exe` на Windows и `badge-farmer` на Linux и macOS.

Если релизов пока нет, воспользуйся [ручной установкой](#ручная-установка).

### Настройка учётной записи Twitch

Открой терминал в папке с распакованной программой.

На Windows открой эту папку в Проводнике, введи `powershell` в адресной строке и нажми **Enter**.

На Windows выполни команду:

```powershell
.\badge-farmer.exe --gen-token
```

На Linux или macOS:

```sh
./badge-farmer --gen-token
```

1. В открывшемся окне браузера войди в учётную запись Twitch, которую хочешь использовать.
2. Подтверди авторизацию на Twitch. Если потребуется, введи код активации из терминала.
3. Вернись в терминал и дождись сообщения `Config saved`.

Если браузер не открылся, перейди по ссылке активации из терминала.

Программа создаст `config.json` с данными твоей учётной записи и токеном, поэтому заполнять поля вручную не нужно.

Не передавай `config.json` другим людям: в нём хранится твой токен доступа.

### О TV-токене

Badge Farmer использует **OAuth-токен Twitch для ТВ-приложений**, полученный через авторизацию устройства.

Команда `--gen-token` получает такой токен автоматически.

Для ручного получения воспользуйся этим [примером авторизации устройства](https://github.com/rdavydov/Twitch-Channel-Points-Miner-v2/issues/94#issuecomment-1360683876).

Используй TV Client ID из `config.example.json` в исходных файлах и оставь параметр `scopes` пустым, как при `--gen-token`.

### Обновление

Останови программу перед заменой на новую версию.

Оставь существующий `config.json` в папке с новым исполняемым файлом или скопируй его туда, если распаковываешь обновление в другую папку.

После обновления этот файл можно использовать без повторного получения токена, пока токен действителен.

Также сохрани `config.json.state.json`, в котором хранится состояние сбора бейджей.

Если Twitch впоследствии отклонит авторизацию, снова запусти `--gen-token` и войди в ту же учётную запись.

## Ручная установка

Используй этот способ, если хочешь запускать программу из исходных файлов.

1. Установи [Bun](https://bun.sh/docs/installation) версии 1.4.3 или новее.
2. Открой [репозиторий](https://github.com/FrostyDeFreeze/twitch-badge-farmer), выбери **Code → Download ZIP** и распакуй архив.
3. Открой терминал в распакованной папке проекта и установи зависимости:

```sh
bun install --frozen-lockfile
```

Если у тебя уже есть `config.json`, скопируй его в папку проекта.

Иначе создай его: выполни следующую команду и пройди авторизацию Twitch по инструкции выше.

```sh
bun run gen-token
```

Для запуска программы используй `bun run start`, а для просмотра доступных бейджей — `bun run list`.

Чтобы использовать описанные ниже параметры CLI, добавь их к команде запуска, например `bun run start --debug` или `bun run start --config account.json`.

## Использование

Выполняй команды из папки с программой и своим `config.json`.

Программа работает в терминале, поэтому оставляй его открытым во время сбора бейджей.

Запуск сбора на Windows:

```powershell
.\badge-farmer.exe
```

На Linux или macOS:

```sh
./badge-farmer
```

Чтобы посмотреть доступные бейджи без запуска просмотра, добавь `--list`:

```powershell
.\badge-farmer.exe --list
```

На Linux или macOS используй `./badge-farmer` вместо `.\badge-farmer.exe` в примерах.

| Параметр                | Действие                                                    |
| ----------------------- | ----------------------------------------------------------- |
| Без параметров          | Собирать бейджи и продолжать проверять появление новых      |
| `--list`                | Показать доступные бейджи без запуска просмотра             |
| `--gen-token`           | Войти через Twitch и сохранить настройки учётной записи     |
| `--help`                | Показать доступные команды                                  |
| `--debug`               | Показать технические подробности и причины пропуска бейджей |
| `--config account.json` | Использовать другой файл конфигурации                       |

Параметры `--debug` и `--config` можно сочетать с режимом запуска, например:

```powershell
.\badge-farmer.exe --list --debug --config account.json
```

Чтобы создать отдельный файл конфигурации, выполни `.\badge-farmer.exe --gen-token --config account.json`.

Для остановки нажми **Ctrl+C**.

Программа сохраняет состояние в `config.json.state.json` и использует его при следующем запуске.

С параметром `--config account.json` файл состояния будет называться `account.json.state.json`.

Если доступных для сбора бейджей нет, программа продолжает проверять появление новых.

Запускай только один экземпляр программы на учётную запись Twitch и не смотри другие трансляции с этой учётной записи во время сбора, иначе Twitch может неправильно засчитывать прогресс.

## Как это работает

1. Проверяет в [StreamDatabase](https://streamdatabase.com), какие бейджи сейчас можно получить за просмотр, и пропускает уже имеющиеся.
2. Выбирает бейдж, отдавая приоритет наградам, по которым уже накоплен прогресс.
3. Находит подходящую трансляцию и смотрит её. Если трансляция обрывается или прогресс перестаёт расти, переходит на другой канал.
4. Отслеживает прогресс через Twitch, забирает готовые Drops и проверяет, появился ли бейдж в твоей учётной записи.

Бейдж отмечается как полученный только после того, как Twitch подтвердит, что он есть у тебя.

### Многодневные бейджи

Для некоторых бейджей нужно смотреть трансляции определённое время каждый день в течение нескольких дней. Программа берёт у Twitch число завершённых дней и время следующего окна, останавливает просмотр после дневной нормы и переходит к другим доступным бейджам.

День считается отдельным 24-часовым окном, а не календарной датой. Если пропустить день, завершённые дни сохранятся, а минуты незавершённого дня сбросятся после закрытия окна.

Для эволюций Pokémon программа сама выбирает нужную цепочку и не меняет значки, которые отображаются у тебя в чате. Для каждой стадии нужен бейдж предыдущей стадии. Если первая стадия выдаётся за подписку или подарочную подписку, программа продолжит цепочку только после того, как Twitch засчитает подписку. Сама программа ничего не покупает.

Оставь программу работать, чтобы она вернулась к следующим окнам, или перезапусти её: прогресс продолжится по данным Twitch. `--list` показывает дневную норму и текущий прогресс, не запуская просмотр и не меняя выбранную цепочку.

## Ограничения

- Собираются только бейджи, которые выдаются за просмотр. Бейджи за подписку, покупку, Bits, посещение TwitchCon и случайные награды программа пропускает.
- Платные эволюции собираются, только если бейдж предыдущей стадии уже есть в твоей учётной записи.
- Один запуск работает с одной учётной записью и смотрит одну трансляцию за раз.
- Условия бейджей берутся из StreamDatabase, где их заполняют пользователи. Если там указано неверное число минут, программа не найдёт подходящую награду на Twitch.

## Решение проблем

**`Found 0 available badges` или нужного бейджа нет в списке.** Запусти программу с `--debug`: для каждого пропущенного бейджа будет указана причина, например `Already owned`, `Paid or unknown cost` или `Event has not started`.

**`persisted query unavailable, update the utility`.** Twitch изменил внутренние запросы. Скачай последнюю версию программы.

**`authorization rejected, run with --gen-token`.** Токен больше не действует. Выполни `--gen-token` и войди в ту же учётную запись.

**Прогресс не растёт.** Проверь, что программа запущена в одном экземпляре и что с этой учётной записи никто не смотрит другие трансляции. Если прогресс стоит 5 минут, программа сама переключается на другой канал.
