# Badge Farmer

[English version](README.md)

Автоматически получает бесплатные бейджи Twitch за просмотр подходящих трансляций, по одному бейджу за раз

## Установка

Установите [Node.js](https://nodejs.org/en/download) версии 22 или новее

Скачайте проект с [GitHub](https://github.com/FrostyDeFreeze/twitch-badge-farmer) через **Code → Download ZIP**, распакуйте архив и откройте терминал в папке проекта

Если у вас установлен Git, выполните

```sh
git clone https://github.com/FrostyDeFreeze/twitch-badge-farmer.git
cd twitch-badge-farmer
```

## Настройка

Выберите автоматическую или ручную настройку

### Создание токена

Выполните команду в папке проекта

```sh
npm run gen-token
```

1. В открывшемся окне браузера войдите в учётную запись Twitch, которую хотите использовать
2. Подтвердите авторизацию на Twitch; если потребуется, введите код активации из терминала
3. Вернитесь в терминал и дождитесь сообщения `Config saved`

Если браузер не открылся, перейдите по ссылке активации из терминала

Команда создаст или обновит `config.json`, сохранив данные вашей учётной записи и токен с использованием Client ID из `config.example.json`
Заполнять поля самостоятельно не нужно

### Ручная настройка

Нужен **OAuth-токен Twitch для ТВ-приложений**, полученный через авторизацию устройства с Client ID из `config.example.json`
Команда `npm run gen-token` получает такой токен автоматически; для ручного получения воспользуйтесь этим [примером авторизации устройства](https://github.com/rdavydov/Twitch-Channel-Points-Miner-v2/issues/94#issuecomment-1360683876)
Оставьте параметр `scopes` пустым, как это делает `gen-token`

Получив токен ТВ-приложения, скопируйте `config.example.json` в `config.json` и заполните поля

```json
{
	"id": "123456789",
	"login": "your_twitch_login",
	"client_id": "ue6666qo983tsx6so1t0vnawi233wa",
	"token": "your_oauth_token"
}
```

| Поле        | Что указать                              |
| ----------- | ---------------------------------------- |
| `id`        | ID вашей учётной записи Twitch           |
| `login`     | Ваш логин Twitch                         |
| `client_id` | Client ID ТВ-приложения                  |
| `token`     | Ваш OAuth-токен Twitch для ТВ-приложений |

Данные учётной записи и Client ID должны соответствовать токену
Их можно узнать через [проверку токена Twitch](https://dev.twitch.tv/docs/authentication/validate-tokens/#how-to-validate-a-token): используйте `user_id` для поля `id`, а `login` и `client_id` скопируйте без изменений

Не делитесь `config.json`: он содержит ваш токен доступа

## Использование

Посмотреть доступные бейджи без запуска просмотра

```sh
npm run list
```

![Доступные бейджи](assets/list.png)

Запустить сбор бейджей

```sh
npm start
```

![Просмотр трансляции и прогресс получения бейджа](assets/start.png)

Пока программа работает, оставляйте терминал открытым
Если доступных бейджей нет, программа продолжит проверять появление новых
Для остановки нажмите **Ctrl+C**; состояние сохраняется в `config.json.state.json` и используется при следующем запуске

Запускайте только один экземпляр программы на одну учётную запись Twitch и не смотрите другие трансляции с этой учётной записи во время сбора бейджей, чтобы не мешать учёту прогресса Drops

Если возникла ошибка авторизации, снова выполните `npm run gen-token` и войдите в ту же учётную запись Twitch

## Как это работает

1. Проверяет в StreamDatabase, какие бесплатные бейджи сейчас можно получить за просмотр, и исключает уже имеющиеся
2. Выбирает бейдж, отдавая приоритет тем, по которым уже накоплен прогресс
3. Находит подходящую трансляцию и смотрит её, пробуя другой канал при ошибках или остановке прогресса
4. Отслеживает прогресс через Twitch, забирает готовые Drops и проверяет, появился ли бейдж в вашей учётной записи
